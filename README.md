## 仓库结构与分类规则

```text
PHYB57-Study-Library/
├── index.html                  # 四大类入口
├── README.md                   # 分类索引与维护规则
├── tutorials/                  # Tutorial、习题课与练习资料
│   ├── tutorials-1-3/
│   ├── algorithm-complexity-big-o/
│   ├── tutorial-5-file-io-plotting/
│   └── tutorial-6-least-squares/
├── lectures/                   # 普通上课讲义，按章节存放
│   ├── chapter-1-python-calculator-logic/
│   ├── chapter-2-variables-data-structures/
│   ├── chapter-3-functions/
│   ├── chapter-4-conditionals/
│   ├── chapter-5-loops-comprehensions/
│   ├── chapter-8-1-complexity/
│   ├── chapter-9-number-representation/
│   ├── chapter-11-file-io/
│   ├── chapter-12-plotting-animation/
│   ├── chapter-16-least-squares-regression/
│   ├── chapter-17-interpolation/
│   ├── chapter-19-root-finding/
│   ├── chapter-20-numerical-differentiation/
│   └── chapter-21-numerical-integration/
├── assignments/                # 作业与习题答案
│   └── problem-set-1/
├── course-info/                # 课程大纲等课程信息
│   └── syllabus-f24/
└── topics/algorithm-complexity-big-o/  # 旧公开链接兼容入口
```

1. Tutorial 与习题课资料放入 `tutorials/`；普通课堂讲义放入 `lectures/`；已完成的作业及答案放入 `assignments/`；课程大纲等放入 `course-info/`。
2. 每份资料使用独立的全小写英文短目录名；原 Notebook 文件名保持不变。
3. 每个目录包含 `index.html` 阅读版、用户提供的原文件和 `README.md` 使用说明；同一章的原版课件 PDF 和讲解版放在同一个目录。目录首页和上方索引同时更新。
4. 旧 `topics/algorithm-complexity-big-o/` 仅为此前分享过的链接保留跳转和原 Notebook；它不是单独的一类资料。

本库用于个人学习资料整理。部分材料包含课程讲义原文、原版课件 PDF 或代码，版权归任课老师和助教所有；仓库未声明开放再利用许可。静态网页的数学排版可能需要联网加载 MathJax。
