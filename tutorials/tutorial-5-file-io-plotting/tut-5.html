OPENING AND WRITING TO TEXT FILES¶

Text files (.txt) contain plain text and are among the simplest and most universal formats for saving simulation outputs, experiment logs, and raw configuration data.

In Python, the built-in open() function is used to interact with files: f = open(filename, mode)

Common access modes include:

  • 'r': Read mode (default). Opens an existing file for reading. Raises FileNotFoundError if the file does not exist.
  • 'w': Write mode. Creates a new file if it does not exist, or overwrites the file if it already exists.
  • 'a': Append mode. Writes new data to the end of the file without erasing existing content.
  • 'r+': Read and write mode (the file must already exist; does not overwrite it on open).
  • 'w+': Write and read mode (creates a new file or completely overwrites existing content).
  • 'a+': Append and read mode (creates a new file if needed, appends to the end).

Remember to always close files after use with f.close() to ensure all buffered data is written to disk and system resources are freed. Alternatively, you can use the with statement, which automatically closes the file even if errors occur.

In [1]:
# writing to a text file in 'w' mode
f = open('sensor_log.txt', 'w')    # will save the .txt file to the directory the notebook is in
for i in range(5):
    f.write(f"Sample {i}: reading = {i * 2.5:.2f} mV\n")
f.close()
print("Successfully wrote initial 5 samples to sensor_log.txt.")

# appending new data in 'a' mode
f = open('sensor_log.txt', 'a')
f.write("Sample 5: reading = 12.50 mV (appended)\n")
f.close()
print("Successfully appended sample 5 to sensor_log.txt.")

# using 'with'
with open('run_summary.txt', 'w') as f_out:
    f_out.write("Status: RUN COMPLETE\n")
    f_out.write("Exit Code: 0\n")
print("Wrote run_summary.txt using 'with' statement.")

READING FROM TEXT FILES¶

Python provides several methods to read data from an opened file:

  • f.read(): Reads the entire content of the file into a single string.
  • f.readline(): Reads a single line up to the next newline character \n.
  • f.readlines(): Reads all remaining lines into a list of strings, where each item is one line.
  • Direct iteration (for line in f:): Iterates through lines one by one without loading the entire file into memory at once (recommended for large files).

When reading lines, strings will retain their trailing newline (\n). Use .strip() to remove unwanted leading and trailing whitespace.

In [2]:
# reading the entire file content at once with .read()
f = open('sensor_log.txt', 'r')
content = f.read()
f.close()
print("Entire Content (read)")
print(content)

# reading into a list of lines with .readlines()
f = open('sensor_log.txt', 'r')
lines = f.readlines()
f.close()
print(f"Lines List (readlines) --- ({len(lines)} lines total)")
print(f"Line 0: {lines[0]}")

# iterating line-by-line using 'with' and stripping newlines
print("\nLine-by-line iteration with .strip()")
with open('sensor_log.txt', 'r') as f_in:
    for idx, line in enumerate(f_in):
        clean_line = line.strip()
        print(f"Line {idx}: {clean_line}")

NUMERICAL DATA IN TEXT FILES (NUMPY SAVETXT & LOADTXT)¶

In scientific computing, data is frequently stored as tables of numbers. In such cases, NumPy's inbuilt functions are useful:

  • np.savetxt(filename, data): Saves 1D or 2D numerical arrays directly to disk in plain text.
  • np.loadtxt(filename): Reads columns of numbers directly into NumPy arrays, automatically ignores lines starting with comments (#).

There are a lot of other functionalities for formatting that you can look into.

In [3]:
import numpy as np

# create a 2D array of simulated trajectory data: [time (s), position (m), velocity (m/s)]
time_vals = np.linspace(0, 4, 5)
pos_vals = 0.5 * 9.81 * (time_vals ** 2)
vel_vals = 9.81 * time_vals

data_matrix = np.column_stack((time_vals, pos_vals, vel_vals))

# save numerical array to a text file with a header and 2 decimal places
np.savetxt('trajectory.txt', data_matrix, fmt='%.2f', header='Time(s) Position(m) Velocity(m/s)')    # fmt specifies numerical format, header specifies column names
print("Saved 2D array to trajectory.txt with header.")

# load the array back from disk
loaded_data = np.loadtxt('trajectory.txt')
print("\nLoaded array back into memory:")
print(loaded_data)

# unpack columns directly into individual variables
t, x, v = np.loadtxt('trajectory.txt', unpack=True)
print(f"\nUnpacked time values: {t}")
print(f"Unpacked position values: {x}")

2D PLOTTING IN PYTHON WITH MATPLOTLIB¶

Python's matplotlib library is the foundational standard for scientific and engineering data visualization. Its sub-module matplotlib.pyplot provides a MATLAB-like plotting interface.

  • Import convention: import matplotlib.pyplot as plt
  • Basic command: plt.plot(x, y) takes coordinate sequences (lists or NumPy arrays) and draws a line or marker plot.
  • Displaying the plot: plt.show() renders and displays the figure.

Customizing Line and Marker Styles¶

The format string argument in plt.plot(x, y, '[color][marker][line]') offers a fast shorthand:

  • Colors: 'r' (red), 'g' (green), 'b' (blue), 'k' (black), etc.
  • Markers: 'o' (circle), '*' (star), 'x' (cross), etc.
  • Line styles: '-' (solid), '--' (dashed), ':' (dotted), '-.' (dash-dot)
In [4]:
import matplotlib.pyplot as plt

# customized line and marker styles with numpy arrays

ENHANCING 2D PLOTS WITH TITLES, LABELS, AND LEGENDS¶

In scientific visualization, plots must always have clearly defined context: axes labels with units, informative titles, and legends to distinguish between multiple curves.

Key plot enhancement commands:

  • plt.figure(figsize=(width, height)): Customizes canvas dimensions in inches for improved readability.
  • plt.title('Plot Title'): Sets a descriptive title above the plot.
  • plt.xlabel('X Axis Label (units)') / plt.ylabel('Y Axis Label (units)'): Labels the axes.
  • label='...' inside plt.plot(): Assigns a label to a dataset for the legend.
  • plt.legend(loc='upper right'): Displays the legend box (loc options include 'best', 'upper left', 2, etc.).
  • plt.grid(True): Toggles grid lines for easier numeric inspection.
  • plt.savefig('figure.png', dpi=300): Exports the figure as an image file on disk.
In [5]:
# generate coordinate data for multiple polynomials

# plot multiple curves with distinct markers, colors, and labels

# add titles, labels, grid, and legend

plt.xlabel('X axis')
plt.ylabel('Y axis')
plt.grid(True, linestyle=':', alpha=0.6)
plt.legend(loc="upper left") 
plt.show()

EXERCISE: Damped Oscillator Comparison¶

A mechanical spring-mass damper satisfies the damped harmonic motion equation: $$y(t) = A e^{-\gamma t} \cos(\omega t)$$

We wish to compare an underdamped oscillator with an overdamped oscillator over $t \in [0, 10]$ seconds.

Given:

  • Amplitude $A = 2.0\text{ m}$
  • Angular frequency $\omega = 3.0\text{ rad/s}$
  • Damping factor 1 (lightly damped): $\gamma_1 = 0.3\text{ s}^{-1}$
  • Damping factor 2 (heavily damped): $\gamma_2 = 1.0\text{ s}^{-1}$

Tasks:

  1. Use np.linspace() to generate 200 evenly spaced time points between $0$ and $10$ seconds.
  2. Compute the positions $y_1(t)$ and $y_2(t)$.
  3. Save $t$, $y_1(t)$, and $y_2(t)$ to a .txt file.
  4. Create a figure with dimensions figsize=(10, 5).
  5. Plot $y_1(t)$ as a blue solid line ('b-', linewidth 2) labeled "Lightly Damped (\gamma = 0.3)".
  6. Plot $y_2(t)$ as a red dashed line ('r--', linewidth 2) labeled "Heavily Damped (\gamma = 1.0)".
  7. Add:
    • Title: "Damped Harmonic Oscillator Response"
    • X-axis label: "Time (s)"
    • Y-axis label: "Position y(t) (m)"
    • A legend positioned in the upper right
    • A reference grid
  8. Display the plot with plt.show().
In [6]:
import numpy as np
import matplotlib.pyplot as plt

# time array
t = np.linspace(0, 10, 200)

# parameters
A = 2.0
omega = 3.0
gamma_1 = 0.3
gamma_2 = 1.0

# compute trajectories
y1 = A * np.exp(-gamma_1 * t) * np.cos(omega * t)
y2 = A * np.exp(-gamma_2 * t) * np.cos(omega * t)

# save data
data_matrix = np.column_stack((t, y1, y2))
np.savetxt('oscillators.txt', data_matrix, fmt='%.2f', header='Time(s) y_1(m) y_2(m)')

# create figure
plt.figure(figsize=(10, 5))

# plot curves
plt.plot(t, y1, 'b-', linewidth=2, label=r'Lightly Damped ($\gamma = 0.3$)')
plt.plot(t, y2, 'r--', linewidth=2, label=r'Heavily Damped ($\gamma = 1.0$)')

# labels, legend, grid, title
plt.title('Damped Harmonic Oscillator Response', fontsize=14)
plt.xlabel('Time (s)', fontsize=12)
plt.ylabel('Position y(t) (m)', fontsize=12)
plt.legend(loc='upper right', fontsize=11)
plt.grid(True, linestyle='--', alpha=0.7)

# display figure
plt.show()
