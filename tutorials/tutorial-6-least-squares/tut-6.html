WHAT IS LEAST SQUARES REGRESSION?¶

In scientific and engineering experiments, model parameters are rarely known a priori. Instead, we must determine them from empirical measurements. However, real-world data inevitably contains sensor inaccuracies, background noise, and measurement errors. Least squares regression is a mathematical method used to find the best-fitting curve or model through a set of data points by minimizing the sum of the squares of the differences (residuals) between observed data and model predictions.

Physical Motivation: Hooke's Law Example¶

Consider an experiment to determine the stiffness $k$ of a linear spring. According to Hooke's Law: $$F(x) = kx$$ where:

  • $F$ is the restoring force measured in the spring (in $\text{N}$).
  • $x$ is the displacement from rest (in $\text{cm}$ or $\text{m}$).
  • $k$ is the spring stiffness (the model parameter to be estimated).

In a laboratory, we apply known displacements $x_i$ and measure corresponding forces $F_i$. Because of measurement noise, no single straight line passes through every data point. Least squares regression allows us to find the most probable stiffness $k$ that best describes the system.

The Estimation Function and Basis Functions¶

In general, least squares regression seeks an estimation function $\hat{y}(x)$ that best fits a dataset of $m$ points $(x_1, y_1), (x_2, y_2), \dots, (x_m, y_m)$.

The estimation function is typically expressed as a linear combination of $n$ basis functions $f_j(x)$: $$\hat{y}(x) = \sum_{j=1}^n \alpha_j f_j(x) = \alpha_1 f_1(x) + \alpha_2 f_2(x) + \dots + \alpha_n f_n(x)$$

Key properties:

  • $\alpha_j$ are the unknown parameters (coefficients) to be determined.
  • $f_j(x)$ are the basis functions, which must be linearly independent (i.e., none can be written as a linear combination of the others). Examples include $f(x) = 1$, $f(x) = x$, $f(x) = x^2$, or $f(x) = \sin(x)$.
  • Notice that "linear" in linear regression means linear in the parameters $\alpha_j$, even if the basis functions $f_j(x)$ themselves are nonlinear in $x$!

Evaluating this estimation function at all $m$ data points yields an $m \times n$ system of equations: $$\begin{aligned} \hat{y}(x_1) &= \alpha_1 f_1(x_1) + \alpha_2 f_2(x_1) + \dots + \alpha_n f_n(x_1) \\ \hat{y}(x_2) &= \alpha_1 f_1(x_2) + \alpha_2 f_2(x_2) + \dots + \alpha_n f_n(x_2) \\ &\;\;\vdots \\ \hat{y}(x_m) &= \alpha_1 f_1(x_m) + \alpha_2 f_2(x_m) + \dots + \alpha_n f_n(x_m) \end{aligned}$$

Minimizing the Total Squared Error¶

For each data point, the individual error (or residual) is defined as: $$e_i = y_i - \hat{y}(x_i)$$

The objective is to minimize the total squared error $E$, which is the square of the Euclidean ($L_2$) norm of the residual vector $\mathbf{e} = [e_1, e_2, \dots, e_m]^T$: $$E = \|\mathbf{e}\|_2^2 = \sum_{i=1}^m e_i^2 = \sum_{i=1}^m \left(y_i - \hat{y}(x_i)\right)^2$$ where:

  • $m$ is the total number of data points.
  • $y_i$ is the actual observed dependent variable.
  • $\hat{y}(x_i)$ is the predicted value from the model at position $x_i$.

The Linear Algebra Set-Up¶

The linear algebra approach formulates the least squares problem as finding the optimal vector $\beta$ that makes $A\beta$ as close as possible to the observation vector $Y$.

Let:

  • $Y$ be the $m \times 1$ column vector of observed values: $$Y = \begin{bmatrix} y_1 \\ y_2 \\ \vdots \\ y_m \end{bmatrix}$$
  • $A$ be the $m \times n$ design matrix whose columns represent the basis functions evaluated at each data point: $$A = \begin{bmatrix} f_1(x_1) & f_2(x_1) & \dots & f_n(x_1) \\ f_1(x_2) & f_2(x_2) & \dots & f_n(x_2) \\ \vdots & \vdots & \ddots & \vdots \\ f_1(x_m) & f_2(x_m) & \dots & f_n(x_m) \end{bmatrix}$$
  • $\beta$ be the $n \times 1$ column vector of parameters to be estimated: $$\beta = \begin{bmatrix} \alpha_1 \\ \alpha_2 \\ \vdots \\ \alpha_n \end{bmatrix}$$

For a simple linear relationship $y = mx + b = \alpha_1 x + \alpha_2$, the basis functions are $f_1(x) = x$ and $f_2(x) = 1$. The matrix $A$ becomes: $$A = \begin{bmatrix} x_1 & 1 \\ x_2 & 1 \\ \vdots & \vdots \\ x_m & 1 \end{bmatrix}, \quad \beta = \begin{bmatrix} \alpha_1 \\ \alpha_2 \end{bmatrix}$$

The model predictions across all data points are compactly written as: $$\hat{Y} = A \beta$$

The total squared error in vector norm notation is: $$E = \|Y - \hat{Y}\|_2^2 = \|Y - A\beta\|_2^2$$

The vector $A\beta$ is a linear combination of the columns of $A$. Therefore, $A\beta$ must lie within the column space (or range) of $A$, denoted $\text{col}(A)$.

In an overdetermined system ($m > n$), experimental noise means $Y$ rarely lies exactly in $\text{col}(A)$. The point $\hat{Y} = A\beta$ in $\text{col}(A)$ that minimizes the Euclidean distance $\|Y - A\beta\|$ is the orthogonal projection of $Y$ onto $\text{col}(A)$.

Consequently, the residual error vector $\mathbf{e} = Y - A\beta$ must be perpendicular (orthogonal) to every column of $A$: $$A^T (Y - A\beta) = \mathbf{0}$$

Recall that the dot product of two vectors is given by $\text{dot}(\mathbf{v}, \mathbf{w}) = \mathbf{v}^T \mathbf{w}$. Setting the dot product with all columns to zero: $$A^T Y - A^T A \beta = \mathbf{0}$$ $$A^T A \beta = A^T Y$$

This fundamental system of linear equations is known as the Normal Equations.

Provided that the matrix $A$ has linearly independent columns (i.e., full column rank $n$), the $n \times n$ matrix $A^T A$ is guaranteed to be invertible. Multiplying by $(A^T A)^{-1}$ yields: $$\beta = (A^T A)^{-1} A^T Y$$

# assemble the design matrix A and target vector Y
# model: y = alpha_1 * x + alpha_2  (slope and intercept)
A = np.vstack([x_disp, np.ones(len(x_disp))]).T   # (m, n) = (30, 2)
Y = F_meas[:, np.newaxis]                         # (m, 1) = (30, 1)  

# compute normal matrix A^T * A and vector A^T * Y
ATA = np.dot(A.T, A)          # equivalent to A.T @ A
ATY = np.dot(A.T, Y)          # equivalent to A.T @ Y

# direct least squares solution via normal equations: beta = (A^T A)^(-1) A^T Y
beta = np.dot(np.linalg.inv(ATA), ATY)
alpha_1, alpha_2 = beta[0, 0], beta[1, 0]    # indexed like so because it's a column vector

print(f"\nEstimated Slope (alpha_1 [k]):      {alpha_1:.4f} N/cm")
print(f"Estimated Intercept (alpha_2 [F0]): {alpha_2:.4f} N")

The Multivariable Calculus Approach¶

The multivariable calculus approach arrives at the exact same solution by treating the total squared error $E$ as an analytical function of $n$ scalar variables $(\alpha_1, \alpha_2, \dots, \alpha_n)$ and finding the point where the gradient is zero.

The error function is: $$E(\alpha_1, \alpha_2, \dots, \alpha_n) = \sum_{i=1}^m \left(y_i - \sum_{j=1}^n \alpha_j f_j(x_i)\right)^2$$ where:

  • $m$ = number of data points.
  • $n$ = number of basis functions.
  • $\alpha_j$ = unknown model parameters.
  • $f_j(x_i)$ = basis functions evaluated at data point $x_i$.
  • $y_i$ = actual/target values.

To find the minimum of $E$, we calculate the partial derivative with respect to each specific parameter $\alpha_k$ (for $k = 1, 2, \dots, n$) and set it equal to zero: $$\frac{\partial E}{\partial \alpha_k} = 0$$

After some computation, we get: $$\sum_{j=1}^n \alpha_j \left(\sum_{i=1}^m f_j(x_i) f_k(x_i)\right) = \sum_{i=1}^m f_k(x_i) y_i \quad \text{for each } k = 1, 2, \dots, n$$

Consider all $n$ equations simultaneously:

  • The term $\sum_{i=1}^m f_j(x_i) f_k(x_i)$ is precisely the dot product of the $k$-th column of $A$ with the $j$-th column of $A$, representing the $(k, j)$-th entry of the matrix $A^T A$.
  • The term $\sum_{i=1}^m f_k(x_i) y_i$ is the dot product of the $k$-th column of $A$ with vector $Y$, representing the $k$-th entry of $A^T Y$.

Hence, the system of $n$ scalar equations can be written in matrix notation as: $$A^T A \boldsymbol{\alpha} = A^T Y$$ $$\boldsymbol{\alpha} = (A^T A)^{-1} A^T Y$$

Both the linear algebra and multivariable calculus approaches yield the identical least squares solution!

Classical Linear Model ($y = mx + b$)¶

For a simple line with two parameters ($m = \alpha_1$ and $b = \alpha_2$), setting $\frac{\partial E}{\partial m} = 0$ and $\frac{\partial E}{\partial b} = 0$ gives us: $$m = \frac{m \sum x_i y_i - \sum x_i \sum y_i}{m \sum x_i^2 - (\sum x_i)^2}, \qquad b = \frac{\sum y_i - m \sum x_i}{m} = \bar{y} - m\bar{x}$$

from scipy import optimize

# generate data: y = 1 + x + (x * noise)

# assemble matrix A and turn y into a column vector
A = np.vstack([x, np.ones(len(x))]).T
y_col = y[:, np.newaxis]

# Method 1: direct least squares regression using normal equations
alpha_direct = np.dot((np.dot(np.linalg.inv(np.dot(A.T, A)), A.T)), y_col)
print("Method 1 (Direct Normal Equation):")
print(alpha_direct)

alpha_lstsq = np.linalg.lstsq(A, y_col)[0]
print("\nMethod 2 (numpy.linalg.lstsq):")
print(alpha_lstsq)

# Method 3: Use optimize.curve_fit from scipy (no need to turn y into a column vector)
def linear_func(x, a, b):
    return a * x + b

alpha_scipy = optimize.curve_fit(linear_func, xdata=x, ydata=y)[0]
print("\nMethod 3 (scipy.optimize.curve_fit):")
print(alpha_scipy)

NONLINEAR REGRESSION: LOGARITHMIC TRANSFORMATIONS¶

Some physical relationships cannot be modeled as linear combinations of basis functions in their native form, but we can sometimes use logarithmic transformations to convert the problem into an equivalent linear form.

1. Exponential Functions¶

Given an exponential model: $$y = \alpha e^{\beta x}$$ where $\alpha > 0$ is a scale factor and $\beta$ is the rate constant.

Taking the natural logarithm ($\ln$) of both sides: $$\ln(y) = \ln\left(\alpha e^{\beta x}\right) = \ln(\alpha) + \beta x$$

Let $\tilde{y} = \ln(y)$ and $c = \ln(\alpha)$: $$\tilde{y} = \beta x + c$$

This is a straight line! We perform standard linear least squares on $(x_i, \tilde{y}_i)$, determine slope $\beta$ and intercept $c$, then recover the original parameters: $$\beta = \text{slope}, \qquad \alpha = e^c$$

2. Power Functions¶

Given a power-law model: $$y = b x^m$$ where $b > 0$ and $x > 0$.

Taking the natural logarithm of both sides: $$\ln(y) = \ln\left(b x^m\right) = m \ln(x) + \ln(b)$$

Let $\tilde{y} = \ln(y)$, $\tilde{x} = \ln(x)$, and $c = \ln(b)$: $$\tilde{y} = m \tilde{x} + c$$

After transforming both $x$ and $y$, we apply linear least squares to solve for slope $m$ and intercept $c$, then recover: $$m = \text{slope}, \qquad b = e^c$$

POLYNOMIAL REGRESSION AND OVERFITTING¶

A polynomial model of degree $n$ is defined as: $$f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_2 x^2 + a_1 x + a_0$$

In Python, NumPy provides a dedicated function to fit polynomials: np.polyfit(x, y, deg). This computes least-squares polynomial coefficients of degree deg.

However, we need to be careful when fitting polynomials to data.

  • Underfitting: Low-order polynomials (e.g., degree 1 for curved data) fail to capture the real physical trend.
  • Overfitting: Higher-order polynomials provide excess flexibility. While they may pass through nearly every training data point (achieving zero training error), they oscillate erratically between points and generalize terribly to new data.

DIRECT NONLINEAR FITTING WITH SCIPY CURVE_FIT¶

Many scientific functions cannot be linearised (e.g., sums of exponentials $y = a_1 e^{-k_1 x} + a_2 e^{-k_2 x}$, sinusoidal functions with unknown frequency, etc.).

In these cases, we perform direct nonlinear regression using scipy.optimize.curve_fit. This uses an iterative method, and so it is a good idea to provide an initial guess (if you don't provide one, SciPy assumes an initial guess of 1 for each parameter). The function returns:

  1. popt: An array of optimal parameter values.
  2. pcov: The estimated covariance matrix of popt. The diagonals $\sqrt{\text{pcov}[j,j]}$ represent the standard errors (uncertainties) of the estimated parameters.

# generate exponential data with noise
x = np.linspace(0.1, 10, 50)
np.random.seed(42)
alpha_true, beta_true = 0.124, 0.28
y = alpha_true * np.exp(beta_true * x) + np.random.normal(0, 0.05, len(x))   # adding random noise to an exponential function

# define the function form
def func(x, a, b):
    y = a * np.exp(b * x)
    return y

# direct nonlinear fitting with curve_fit
popt, pcov = optimize.curve_fit(func, xdata=x, ydata=y, p0=[0.1, 0.2])
alpha_fit, beta_fit = popt[0], popt[1]
alpha_err, beta_err = np.sqrt(pcov[0, 0]), np.sqrt(pcov[1, 1])

print(f"Fitted parameters: alpha = {alpha_fit:.6f} +/- {alpha_err:.6f}")
print(f"                   beta  = {beta_fit:.6f} +/- {beta_err:.6f}")

# plot the data and fit
plt.figure(figsize=(10, 6))
plt.plot(x, y, 'b.', label='Noisy Experimental Data')
plt.plot(x, func(x, alpha_fit, beta_fit), 'r-', linewidth=2,
         label=f'Direct Fit: $y = {alpha_fit:.3f} e^{{{beta_fit:.3f}x}}$')
plt.xlabel('x', fontsize=11)
plt.ylabel('y', fontsize=11)
plt.title('Direct Nonlinear Fitting with scipy.optimize.curve_fit', fontsize=13)
plt.legend(loc='upper left', fontsize=11)
plt.show()
